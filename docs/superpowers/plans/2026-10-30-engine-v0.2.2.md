# Parlato: move to voice-engine v0.2.2

Approved by Miguel on 2026-10-30. Source of truth: the Notion page "Voice Apps Engine Sync", sections "Every app: move
to v0.2.2" and "Parlato: move to v0.2.2". Engine docs: https://github.com/mmnzns/voice-engine/tree/v0.2.2 (README and
`docs/building-helpers.md`). Branch `engine-v0.2.2`, based on `chore/remove-live-words` (PR #15). Releases are held.

## Rules

- Code flows from the engine into Parlato only. Never copy Parlato code into the engine, never edit engine code. If the
  engine is wrong or missing something, stop and report it (it becomes an issue on mmnzns/voice-engine).
- Every engine crate at `tag = "v0.2.2"`, all on the same tag.
- New Mac-only code in `*_macos.rs` files, `cfg` dispatch only in shared files.
- Keyboard-hook code (`hotkeys/keyboard_hook*.rs`) is off-limits.
- Tests and dev runs never touch the real shared model folder: tests use `SharedStore::open_at` with a temp folder.
- Logs never contain dictated text, prompts or replies.
- Each unit ends with `cargo test --lib`, `cargo clippy --lib`, `npx tsc --noEmit`, `npm run build`, and one commit.

## Decisions

1. **What runs where.**
   - Speech runs in Parlato's process through `voice-engine-stt` (`load`, `vad::detect`; imported Whisper files
     through `whisper_engine::WhisperEngine::load(path, opts)`).
   - Local AI runs in the engine's AI helper through `voice_engine_client::LlmClient`.
   - On Windows, Whisper stays on the processor in process, as in 0.14.1. No Vulkan speech helper in this release. The
     graphics card covers Parakeet (DirectML) and the AI (Vulkan helper). So Parlato ships one AI helper (`parlato-llm`)
     plus `parlato-llm-vulkan` on Windows x64, and no speech helper.
2. **Model ids** are the engine catalog's ids from now on. A one-time settings migration rewrites old ids:
   - the global store keys `selected_whisper_model`, `selected_parakeet_model` and `llm_selected_gguf`;
   - every Power Mode row (`whisper_model_id`, `parakeet_model_id`) in `parla.power_mode.json`.

   The table is in the engine's `legacy.rs`, `parlato_entries()`, for example `ggml-large-v3-turbo-q5_0` becomes
   `whisper-turbo` and `parakeet-ultra-0.6b-int8` becomes `parakeet-ultra`. Write Parlato's own table from the
   ids, not by importing engine internals. Imported Whisper ids (`imported:<stem>`) stay as they are.
3. **Startup order.** In `setup`, before anything can load a model:
   1. `SharedStore::open(App::Parlato)`.
   2. Migrate the settings ids.
   3. `move_in(&used)`, where `used` is every catalog id the settings and Power Modes point to, plus `vad` when voice
      detection is on.
   4. `collect()`.

   Log the `MoveReport` (ids and counts only).
4. **Local AI.**
   - **Catalog models:** `catalog::local_ai()` (Qwen 3.5 4B and 9B, Granite 4.2 3B; Granite stays Parlato's default and
     recommendation).
   - **Imported models:** every non-catalog `*.gguf` directly in `LlmModels/` and in `LlmModels/imported/`, with id
     `voice_engine_models::imports::import_id(path)` and the file stem as its name. They load by path, are never
     moved, and Delete only removes a file in `LlmModels/imported/` (as today).
   - **Saved choice:** an `llm_selected_gguf` that pointed at a dropped model or an `imported:<stem>` becomes that
     file's import id.
5. **The AI helper.**
   - It starts with the app, and when the AI provider is `llamacpp` the selected model loads at startup (`load`).
   - After a dictation the model stays loaded for "Keep models ready" (`model_keep_alive_secs`, the same setting as
     speech), then is unloaded. The helper itself never exits while the app runs (no idle exit).
   - Loading starts again when a recording starts, so it overlaps the recording.
   - Requests:
     - Thinking is off.
     - `max_tokens` is `llm_gguf_max_tokens`, and the context size is `llm_gguf_context_size`.
     - The 60 s generation limit stays.
     - Cancel works.
   - `llm_gguf_n_gpu_layers` is retired (see 6).
   - On quit, `shutdown`.
6. **Graphics card.** There is one setting, `use_gpu`, for speech and AI. It replaces `parakeet_gpu` and
   `llm_gguf_n_gpu_layers`, and the UI shows one switch.
   - **Default:** on the Mac, true. On Windows, `voice_engine_stt::discrete_card().is_some()`, worked out only while
     the person has not set it. An `Err`, a timeout or `None` means off.
   - **Migration:** `parakeet_gpu == true` becomes `use_gpu = true`. Anything else gets the default.
   - **Every load and request** passes it.
   - **When `fell_back` is true** (speech `backend().fell_back` or AI `Outcome` `fell_back`): call the existing
     `note_gpu_failure` path and show the "Graphics card failed, used processor" notice once. Then pass `gpu: false`
     for that runtime until restart. Exception: on the Mac, ONNX models (Parakeet, Unified, Nemotron) always report
     `fell_back` for `gpu: true`. Never show the notice for them on the Mac; pass `gpu: false` to them on the Mac.
7. **Speech pipeline stays Parlato's:**
   - voice detection first (engine `vad::detect` with the catalog `vad` model);
   - Whisper gets the whole recording;
   - Parakeet TDT keeps `parakeet_windows.rs` (14.96 s windows, merged on timed words). It now merges the engine's
     words instead of `parakeet_rs::TimedToken`; use a Parlato struct.

   Also:
   - **Language:** Whisper's language hint; Nemotron's language goes to `ChunkOptions::language`.
   - **Threads:** `speech_threads` goes to `LoadOptions::threads`. Auto means `None`, the engine's rule.
   - **Keep-alive:** stays as it is.
   - **`ModelHandle`:** hold one from `store.hold(id)` while a model is loaded, and drop it on unload.
   - **Dictionary words:** they are not sent to local Whisper today and are not added now (parity). The
     `transcribe_wav` command keeps its `initial_prompt`, passed as `vocabulary`.
8. **Models screen and commands.** Keep the Tauri command names and event names the frontend uses, so the UI changes
   stay small:
   - `list_*` comes from `store.list()` and the catalog.
   - `download_*` is `store.download` on a blocking thread, with a cancel flag and progress events mapped to the
     existing payloads.
   - `delete_*` unloads if loaded, then calls `store.release(id)`.
   - VAD uses the catalog id `vad`.
   - A model another app deleted shows as missing with Download.
   - `StoreError::DownloadingElsewhere` shows as downloading.
   - Model names and notes: add `modelText.<id>` entries for the new ids in every locale file. Keep the meaning of
     today's texts, and give Qwen 3.5 4B and 9B a plain note.
9. **Delete all data** calls `store.release_all()` first, then removes Parlato's folders as today.
10. **Removed:**
    - Parlato's downloader (`download.rs`) and its three model managers, and the old catalogs `transcription/model.rs`
      and `GGUF_MODELS`;
    - `whisper.rs`, `parakeet.rs` (runtime parts), `vad.rs` (runtime and download) and `llamacpp.rs` (runtime parts);
    - the `whisper-rs`, `parakeet-rs` and `llama-cpp-2` dependencies, and the `cuda*` features (CUDA was never
      shipped);
    - `/FORCE:MULTIPLE` in `.cargo/config.toml`.

    Keep `gpu-detect` only if something still uses it. Otherwise remove it and `gpu.rs`, and point the hardware label
    at `use_gpu` and the backend in use.
11. **Build.**
    - `src-tauri/.cargo/config.toml` gets the engine README's whole "Build settings an app must copy" block.
    - Helpers come from the reusable workflow `mmnzns/voice-engine/.github/workflows/build-helpers.yml@v0.2.2`
      (`engine-ref: v0.2.2`, `helpers: llm,llm-vulkan`, `llm-name: parlato-llm`) and are listed in `externalBin`.
      `parlato-llm-vulkan` is listed only in the Windows x64 job (a `--config` override file).
    - Local dev uses `scripts/fetch-helpers.sh`, which runs the engine's `scripts/build-helpers.sh` from a clone at
      v0.2.2 outside the repo into `src-tauri/binaries/`. That folder is git-ignored. CI's test job creates
      placeholder sidecar files so `tauri-build` passes.
    - `scripts/cpu-baseline.ps1` checks `whisper-rs-sys` only (llama.cpp is no longer in the app) and adds the `-O2`
      check on its CMake cache.
    - The NSIS installer hook closes running `parlato-llm*.exe` before installing.
    - The macOS release signs the sidecars with the app identity. Check with `codesign --verify --deep --strict`.

## Units (each one a Sonnet task, reviewed before the next)

1. **Plumbing.**
   - Add the engine crates (`voice-engine-protocol`, `-client`, `-stt` with `directml` on Windows, `-models`).
   - Copy the `.cargo/config.toml` block, write `scripts/fetch-helpers.sh`, add `externalBin` and the `binaries/`
     ignore, and the CI placeholder step.
   - The old crates stay for now; the app builds and runs as before.
2. **Models and settings.**
   - The store module (startup open, migrate, `move_in`, `collect`) and the id migration, with tests on a temp folder
     and a fake old layout.
   - Rewrite the model commands on the store, keeping command and event names.
   - Imports, Delete all data, and frontend id changes plus locale texts.
   - The old runtimes read models from the store folders (catalog file names match Parlato's old names).
3. **Speech runtime.** Swap Whisper, Parakeet, Unified, Nemotron and voice detection to `voice-engine-stt`. Keep
   the pipeline, windowing, keep-alive, threads, language and notices. Remove `whisper.rs`, the parakeet runtime,
   `vad.rs` and the `whisper-rs` and `parakeet-rs` deps. Port the ignored smoke tests to the engine API.
4. **Local AI.** `llamacpp.rs` uses `LlmClient` with the helper sidecar: startup load, keep-alive unload, reload at
   recording start, thinking off, limits, cancel and shutdown. Remove `llama-cpp-2` and `/FORCE:MULTIPLE`, and offer
   the catalog models plus imports.
5. **Graphics card.** The `use_gpu` setting, its default, migration and one switch in the UI, plus fallback notices.
6. **Release and CI.** The `release.yml` helpers job and sidecars, the Windows x64 override, the cpu-baseline script,
   the NSIS hook, the Mac signature check. Update `ci.yml`.
7. **Docs.** The CLAUDE.md "Shared engine" snippet, the CHANGELOG `[Unreleased]` entry, THIRD_PARTY_NOTICES
   (voice-engine, MIT) and BUILDING.md.

Then on the Mac: tests, a release build of the `.app` signed locally, and the real update path from 0.14.1 (see the
manifest in the scratchpad).
