# Release 0.16: every review fix and the whole Roadmap

Owner decision (Miguel, 2026-11-13): ship everything pending in one release,
Mac and Windows. For this release only, the owner allows changes to
`src-tauri/src/hotkeys/`, `src-tauri/src/audio/` (capture included) and
`src-tauri/src/screen_context/`, with extra care: tests for every behaviour
change, Windows paths kept working, and a hand-test checklist for Miguel.

Base branch: `qa/review-2026-11` (the review fixes, the two 0.15.2 fixes, the
dotted background removal, the UI preview). Each work package below runs on
its own branch and worktree, cut from the base, and is merged back one at a
time after review. Release version: 0.16.0.

## Rules for every package

- Read `CLAUDE.md`. Engine code (`voice-engine` crates) is never edited from
  here; open an issue on `mmnzns/voice-engine` instead and report it.
- Mac-only code goes in `*_macos.rs`; Windows-only in `cfg(windows)` files.
  Every feature states what it does on each platform. If a feature is
  Mac-only by nature (Fn key, AppleScript), Windows must be unchanged.
  Windows code can't be compiled on the Mac: read it carefully; CI builds it.
- Logs never contain dictated text, window titles, URLs with paths, or keys.
- Every new string in en, es (tú) and fr (vous); key sets stay identical.
- Tests for logic; `cargo test --lib`, `npx tsc --noEmit`, `npm run build`
  must pass; no new clippy warnings. Mock new commands in
  `dev/ui-preview/mocks.ts`.
- Never launch the app, never touch real data, never change system settings
  or click Allow. Don't run `cargo fmt` on the whole crate.
- Each package ends with a hand-test list for Miguel (Mac and Windows).

## Product decisions made for this release (Miguel can veto)

- **Spoken commands:** a "Spoken commands" setting (on by default) for
  "new line", "new paragraph" and "scratch that" (removes the last sentence
  of the current dictation), in English, Spanish and French. Punctuation
  words ("comma", "period") are a separate setting, off by default.
  **Snippets:** a list on the Dictionary page: say a trigger phrase, get the
  saved text.
- **Edit before paste:** a "Review before pasting" setting, off by default.
  When on, the pill opens a small editor with the text; Enter pastes into the
  app you were in, Esc keeps it in History only.
- **Statistics:** Home gets a small chart of words per day for the last 14
  days, with a week view. Data comes from History.
- **Dictionary learning:** after you edit a dictation's text in History,
  Parlato suggests the changed words for the Dictionary ("Add to Dictionary?").
  Nothing is added without a click. Import and export as a CSV file.
- **Quick History in the tray:** the last three dictations, each with Copy.
- **Power modes:** right-click a mode for Duplicate, Rename and Delete.
- **Double-tap:** double-tap the dictation key to start hands-free; tap again
  to stop. A setting, on by default, both platforms.
- **Custom shortcuts:** two modifiers alone (Ctrl+Win, Ctrl+Alt), Left Win,
  Caps Lock and the Menu key as single keys, left vs right sides in
  combinations, Escape allowed (the recorder closes with its button), and a
  clear message for shortcuts the system already uses.
- **Fn / Globe key (Mac):** offered as a single key, with a note that macOS may
  also use it for emoji or dictation (System Settings > Keyboard).
- **One Delete button per model:** if other apps use the model, the dialog
  offers "Delete from Parlato" or "Delete everywhere and free X GB".
- **Setup wizard:** the model step needs a model in use to continue (Skip
  stays); the language you speak is asked first, and the matching model shows
  a "Recommended" tag. Granite is "Recommended" for AI cleanup.
- **OpenRouter as a speech provider:** only if OpenRouter offers a real
  transcription endpoint; otherwise reported and left on the Roadmap.
- **SenseVoice Small:** needs the shared engine: an issue goes to
  `mmnzns/voice-engine`; Parlato adds it once the engine ships it.
- **Apple Developer ID:** a purchase, not code. Stays a decision for Miguel.

## Work packages

1. **Reliability (backend):** audio capture freezes (a "starting" flag instead
   of holding the recorder lock across the device open; no blocking join on
   timeout), microphone unplugged or disk full mid-recording (stop and tell
   the user), power-mode baseline saved and restored after a crash, log size
   checked while running, API key reads not blocking other keys, pill events
   tagged with the dictation so a late event can't reach a newer pill,
   a notice when History can't open, the remaining slow commands made async,
   a command listing downloads in progress, the four known clippy warnings.
2. **Setup and models (frontend):** one Delete button, Recommended tags,
   language first in the wizard, Continue needs a model, a sidebar download
   indicator that survives leaving the page (uses package 1's command),
   clickable pill failures that open the right page, the microphone row's
   System Settings button only when needed, Voice detection wording, leftover
   key names, translations still in English.
3. **Shortcuts (hotkeys):** custom shortcuts, double-tap, Fn/Globe, reserved
   shortcut messages, readable key names in the sidebar and tray.
4. **Mac features:** website pairing for Power modes (AppleScript, with the
   Automation permission explained), the pill above full-screen apps
   (non-activating panel), AI cleanup reading the screen with Apple Vision
   (Screen Recording permission explained).
5. **Text features:** spoken commands, snippets, edit before paste.
6. **History features:** statistics on Home, dictionary learning and
   import/export, Quick History in the tray, Power mode right-click actions,
   OpenRouter speech (if possible), the SenseVoice engine issue.

Order: 1, 2, 3, 4 and 6 in parallel; 5 after 1 is merged (both change the
pipeline). Then a full review, CI on Mac and Windows, and Miguel's hand tests.
